## 預約前先確認這 6 件事

| 項目 | 建議先確認 |
| --- | --- |
| 本人意願 | 長輩自己是否願意接受服務 |
| 當天狀況 | 是否發燒、明顯不適、頭暈或急性疼痛 |
| 近期醫療 | 是否近期手術、住院、骨折或醫師有特別限制 |
| 皮膚與外傷 | 是否有傷口、紅腫或不適合碰觸區域 |
| 力道偏好 | 從較溫和開始，過程中持續詢問感受 |
| 服務空間 | 防滑、無雜物、起身與移動都安全 |

## 1. 年齡不是唯一判斷，當天狀況更重要

同樣 70 歲，有人日常活動很多，有人可能剛出院或正在恢復期，不能只用年齡決定適不適合。

若有近期手術、骨折、急性疼痛、發燒、明顯頭暈、醫師交代限制活動等狀況，應先詢問合格醫療專業人員。一般按摩不能取代醫療評估。

<p class="note">Move Time 不以「改善循環、治療退化、復健、止痛」等醫療效果作為服務承諾。樂齡方案的定位是一般居家放鬆與舒緩。</p>

## 2. 長輩服務不追求越痛、越大力越好

對樂齡族群，服務過程更需要頻繁確認：

- 這個力道可以嗎？
- 這個姿勢舒服嗎？
- 要不要換一個位置？
- 有沒有哪個部位不要碰？

如果長輩不習慣表達，家屬可以在服務開始前協助說明，但過程中仍應尊重長輩本人的感受與意願。

## 3. 60 分鐘的價值，在於「不需要一次做很久」

Move Time 樂齡孝親舒緩目前設計為 60 分鐘 NT$1,600。對長輩來說，時間不是越長越好；以一個容易安排、能清楚溝通的時段開始，通常比追求長時間更好掌握。

## 4. 家裡空間要特別注意防滑與起身動線

樂齡到府的優點，是長輩不用為了服務外出、上下車或找停車。但也因為在家裡，服務區周圍要先整理：

- 移除電線、地墊捲邊與容易絆倒的物品。
- 確認床邊或服務位置附近有足夠移動空間。
- 地板若容易滑，要先處理。
- 服務後起身不要急，依本人狀況慢慢坐起或站立。

Move Time 目前不攜帶按摩床，因此要先準備穩定、舒服且適合服務的位置。

## 5. 家屬要不要在旁邊？看長輩意願與需要

如果長輩第一次接受到府服務、聽力不佳、需要協助表達，家屬在附近會比較方便。但不一定要全程站在旁邊盯著；只要聯絡得到、能在需要時協助即可。

若長輩重視隱私，也應尊重本人感受。真正重要的是服務前已把需求、健康疑慮與避開部位說清楚。

## 6. 哪些情況不要急著安排按摩？

如果出現明顯急性不適、跌倒後仍疼痛、發燒、傷口、突然不尋常的症狀，或家屬自己也在問「這會不會是疾病」，這時候就不是靠一般按摩判斷的問題。

先就醫或詢問合格醫療專業人員，等狀況適合再安排放鬆服務，比「先按看看」安全。

## 幫長輩安排服務，重點是「舒服、清楚、可停止」

只要記得：本人願意、身體狀況適合、避開醫療風險、力道能隨時調整、現場安全，這些都比追求「按很久、按很重」更重要。
