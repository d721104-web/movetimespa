第一條　定義

  1. 「服務」：指乙方依本契約，於客戶指定處所提供之到府按摩與放鬆舒緩服務。
  2. 「客戶」：指經甲方客服、網站、官方通訊帳號或其他甲方管理之預約管道完成預約之人。
  3. 「分潤基準服務費」：指甲方於該筆派單成立時，就該服務品項對外公告或向客戶確認之標準服務價，加計已確認之指定、夜間、偏遠地區或超時等加價；不包含客戶自願給付之小費。甲方自行提供之折扣、優惠券或行銷優惠，不減少分潤基準服務費，但乙方事前就特定活動以書面同意者除外。
  4. 「分潤比例」：指乙方就每筆服務所得請求之承攬報酬比例，依第六條及附件一定之。
  5. 「服務報酬」：指分潤基準服務費乘以乙方適用之分潤比例所得之金額。
  6. 「可接單時段」：指乙方自行向甲方登記、表示願意接收媒合訊息之時間區間。
  7. 「派單」：指甲方向乙方提出個別服務案件之媒合要約；乙方接受後，始成立該筆個別服務承攬。
  8. 「書面」：包含紙本、電子郵件、可保存且可辨識發送人之官方通訊軟體訊息及依法有效之電子文件。

第二條　契約性質與雙方關係

  1. 本契約為民法承攬關係。乙方以自己之專業技能及判斷，獨立完成其所接受之個別服務案件，並依完成之工作取得承攬報酬。
  2. 在雙方實際合作方式符合獨立承攬之前提下，雙方不成立僱傭關係；甲方不以雇主身分為乙方辦理勞工保險、就業保險或提繳勞工退休金。全民健康保險及乙方其他社會保險，依乙方依法應適用之身分辦理。
  3. 雙方確認並應共同維持下列實際合作原則：乙方自行決定可接單時段與接單總量；乙方可自由拒絕個別案件；甲方不設最低接單數、固定班表、強制待命、考勤打卡、考績、升遷、扣點或罰款制度；乙方得同時受僱於他人、與其他平台合作或自行執業；乙方不納入甲方組織編制，教育訓練原則上由乙方自行決定是否參加。
  4. 雙方知悉契約性質由主管機關及法院依實際履行狀況與從屬性程度實質認定，不因本契約名稱而當然確定。若日後實際合作方式發生重大改變，致有成立勞動關係之可能，雙方應立即檢視並依法調整，不得以本契約規避強制法令。

第三條　合作服務內容與法令界線

  1. 乙方提供之服務，以到府按摩、指壓、肩頸放鬆、全身放鬆、足部放鬆、精油香氛放鬆、樂齡舒緩及雙方另行確認之非醫療民俗調理服務為限。
  2. 本服務以紓解筋骨、消除疲勞及一般放鬆舒緩為目的，屬非醫療行為。乙方不得進行診斷、治療、復健、針灸、傷科醫療、疾病或藥物諮詢，不得宣稱療效，亦不得使用足使一般人誤認為醫事人員或醫療服務之名稱與表述。
  3. 如客戶有急性疼痛、外傷、發燒、傳染風險、意識異常、疑似需醫療處置之狀況，或乙方依專業判斷不宜服務，乙方得拒絕或中止服務，並建議客戶尋求合格醫療專業協助。
  4. 甲方負責品牌經營、行銷、客服接單、客戶預約資料管理、派單媒合、服務費收款、報酬結算、客訴受理及安全事件支援。客戶如於現場以現金付款，乙方僅於甲方明確授權之範圍內代收，並依甲方提供之對帳方式辦理。
  5. 乙方負責於接受個別案件後依約前往服務地點、以其專業完成服務、進行必要之服務前後溝通，並遵守本契約所定安全與個資規範。
  6. 除甲方另有明確書面授權外，乙方無權以甲方名義對客戶承諾折扣、退款、療效、保證結果或締結本契約以外之交易。
  7. 服務區域以臺南市為主要範圍；超出乙方自行登記之服務地區者，須經乙方就個案另行接受。

第四條　服務方法之自主

  1. 乙方就合法服務範圍內之手法選擇、力道、節奏、部位順序及時間分配，依其專業判斷及客戶當下狀況自主決定。
  2. 甲方提供之服務流程、手技範例、教育資料與訓練，除法令、安全、個資或品牌識別所必要者外，原則上屬建議與資源，不構成日常工作指令。
  3. 乙方得自行使用其慣用且符合法令及安全衛生要求之精油、乳液或其他耗材；如甲方要求使用特定品牌或規格之耗材，應由甲方無償提供或事前與乙方另行書面約定費用。
  4. 乙方服裝原則上自主，但應符合清潔、衛生、安全及一般專業服務之合理標準。甲方如提供品牌識別服裝、識別證或出勤用品，係供客戶辨識及安全管理使用，不作為僱傭考勤或人事管理之依據。
  5. 因按摩服務具高度專屬性及客戶信賴基礎，乙方接受個別案件後原則上應親自履行；乙方無法履行時，應儘速通知甲方，由甲方重新媒合，不得自行將甲方客戶資料交付第三人。

第五條　時段自主、派單與取消

  1. 乙方自行決定並登記可接單時段、服務地區及可承接之服務項目，並得隨時調整；甲方不得要求最低時數、最低接單量或固定待命。
  2. 甲方提出派單後，乙方得自由接受或拒絕，無須說明理由。甲方不得僅因乙方拒絕單一或多筆案件而扣減報酬、調降既有分潤級距、罰款或為其他懲罰性處分。
  3. 乙方接受派單後因故無法履行者，應儘速通知甲方以利改派。若乙方於服務開始前二小時內取消，三個月內累計逾三次且無正當理由，甲方得提出合作檢討；協商不成時，任一方得依第十七條終止契約，但甲方不得因此扣減已完成服務之報酬或另課違約金。
  4. 客戶於服務開始前取消或無法履約時，尚未完成之服務原則上不生服務報酬；如乙方已到達服務地址而客戶無故失聯、拒絕進場或臨時取消，甲方應協助處理客戶費用，並補償乙方因此已實際發生且可證明之必要停車費、通行費等直接交通支出。安全事件之中止另依第十條辦理。
  5. 甲方媒合個別案件時，得依乙方自行登記之時段、地區、服務項目、距離、客戶指定及其他與案件履行直接相關之客觀因素決定；不得以乙方私人生活、與服務無關之言論或與甲方以外之工作關係作不利差別待遇。
  6. 乙方得向甲方查詢自身已接受、完成及取消之案件紀錄。

第六條　服務報酬與分潤級距

  1. 乙方之服務報酬，按每筆分潤基準服務費乘以乙方當期適用之分潤比例計算。
  2. 分潤比例分為入門 60%、進階 65%、資深 70%，客觀門檻詳附件一。
  3. 新加入乙方自入門 60% 起算；達附件一客觀門檻者，自次一結算期起自動適用較高級距，甲方應主動通知。
  4. 已取得之較高分潤級距，不因一般客戶評價波動、拒絕個別派單、暫停接單或依法／依約行使安全權利而調降。
  5. 客戶評價僅得作為服務改善、客戶偏好及案件媒合之參考，不作為扣款、罰款或單方降級之依據。若有具體重大違約或侵權事件，應依本契約之查明、終止及損害賠償機制處理。
  6. 客戶自願給付之小費全數歸乙方所有。
  7. 甲方自行提供之折扣、優惠券或行銷優惠，由甲方吸收，不得減少乙方分潤基準；但乙方事前就特定活動以書面同意共同負擔者除外。
  8. 附件一門檻如有調整，僅適用於調整生效後尚未取得該級距者；甲方應於三十日前以書面通知，且不得溯及既往降低乙方既得級距。

第七條　結算、對帳與給付

  1. 每月一日至十五日及十六日至月末日各為一結算期。
  2. 甲方應於各結算期結束後五個工作日內提供逐筆明細，至少包含服務日期、案件編號、服務品項、分潤基準服務費、分潤比例、應付報酬及依法扣繳項目。
  3. 乙方對明細有異議者，原則上於收到後十四日內提出；計算錯誤、漏列或依法不得放棄之請求，不因未於前述期間提出而消滅。
  4. 甲方應於各結算期結束後十個工作日內，將報酬匯入乙方指定帳戶；匯款手續費由甲方負擔。
  5. 甲方遲延給付已確定之報酬時，依法負遲延責任；雙方並同意以年利率百分之五計算遲延利息，但法律另有強制規定者從其規定。
  6. 除法令要求之扣繳、乙方個別書面同意或雙方已確認之抵銷外，甲方不得逕自從乙方報酬中扣除客訴費用、罰款、扣點或其他款項。
  7. 乙方已完成服務或依第十條合理中止服務者，其服務報酬不因客戶嗣後拒付、遲付或甲方自行退款而受影響；如乙方就該事件另依法應負賠償責任，應依第十八條另行處理。

第八條　費用負擔與禁止收費

  1. 甲方不得向乙方收取保證金、押金、加盟金、介紹費、平台使用費、強制訓練費或其他與取得派單資格相類之費用，亦不得要求乙方購買特定商品或投資。
  2. 甲方不得扣留乙方身分證、護照、工作證、證照正本或其他重要證件。
  3. 基礎合作說明、手技評估及必要之安全／個資流程說明，甲方不另行收費。
  4. 乙方原則上自行負擔一般往返交通費、個人慣用耗材、個人保險及其依法應負擔之稅費。乙方自行選擇交通方式；如自行駕駛汽機車，應依法持有有效駕駛資格並維持法定強制保險。
  5. 甲方指定之品牌識別用品及指定耗材，如要求乙方於案件使用，應由甲方無償提供。可重複使用之物品於契約終止時應返還；正常耗損不負賠償責任。

第九條　最低服務與安全標準

  1. 乙方應於服務前以合理方式確認客戶需求及是否有不宜接受一般按摩之明顯狀況；服務中應適時確認力道與舒適度，發現異常時得調整或停止。
  2. 乙方應維持手部、用品與耗材之合理清潔衛生，並遵守民俗調理業及其他適用法規之衛生與安全要求。
  3. 乙方接受案件後應於約定時間合理準時到達；如預見遲到，應儘速通知甲方客服以利轉知客戶。單純遲到不當然構成罰款或扣款事由。
  4. 乙方不得於服務中飲酒、使用非法藥物或在明顯不適合提供服務之身心狀態下勉強出勤。乙方因自身健康、安全或其他正當理由拒絕或中止服務者，不因而受懲罰性處分。
  5. 除於法律允許範圍內為自身人身安全所必要之即時蒐證、依法配合調查或經客戶明確同意外，乙方不得於服務場所拍攝、錄音或錄影；不得揭露客戶姓名、地址、影像或其他可識別資料。
  6. 甲方不得以群組公告、口頭指示或內部規章，單方增加具有契約拘束力之排班、罰款、最低接單、競業或其他重大義務；但個別案件之地址、預約資訊、客戶偏好及法令／安全緊急通知，不在此限。

第十條　到府安全保障與不當要求之處理

  1. 甲方應建立客戶資料登錄、異常紀錄及黑名單機制。就甲方已知之客戶重大異常、安全警示或服務地點風險，應於派單前提供乙方判斷是否接案所必要之資訊。依法有職業安全衛生法第二十六條或其他風險評估、危害告知義務之適用時，甲方應依法辦理。
  2. 乙方於到達、服務開始及服務結束時，依甲方提供之安全機制完成簡要回報。該回報僅供到府服務之人身安全、案件紀錄與緊急應變使用，不作為工時考勤、固定出勤管制或薪資計算之依據。
  3. 乙方於現場遇有下列情形，得立即停止服務並離開，無須事先取得甲方同意：客戶要求或暗示性服務／性交易；對乙方為性騷擾或不當碰觸；未經同意拍攝、錄音或錄影；飲酒過量、施用毒品或明顯神智不清；有暴力、恐嚇、脅迫、限制自由或無法安全離場之情形；現場有未事前告知且足以造成安全疑慮之不明人士、危險物品或環境；或其他乙方依當時客觀情況合理判斷有人身安全疑慮之情形。
  4. 乙方依前項善意且合理判斷中止服務者，甲方應按該案件原本應適用之分潤基準及分潤比例，全額給付乙方該筆「服務報酬」，不因服務提前中止、客戶拒付或後續爭議而扣減。
  5. 除有具體證據足認乙方故意虛偽陳述安全事件外，甲方不得事後以情節輕微、客戶無惡意或可繼續觀察等理由否定乙方之現場安全判斷。
  6. 甲方接獲安全事件回報後，應優先確認乙方安全，必要時協助報警、就醫、交通離場、證據保全及法律資源；並應立即停止該客戶之後續派單，待風險評估完成後始得決定後續處理。
  7. 甲方不得因乙方依本條行使拒絕、離場、報警、申訴或其他救濟權利，而扣款、降級、減少派單作為報復、終止契約作為報復或為其他不利處分。

第十一條　性騷擾與性交易零容忍

  1. 本合作禁止任何形式之性交易、猥褻服務、性暗示招攬及性騷擾。甲方不得要求、暗示或默許乙方提供此類服務，乙方亦不得主動提供、招攬或與客戶另行約定。
  2. 乙方於服務過程遭遇疑似性騷擾時，得依第十條立即中止服務並向甲方進行「內部安全事件通報」。甲方之內部通報及協助機制，不取代乙方依法向警察機關、地方主管機關、司法機關或其他有權機關提出申訴、告訴或救濟之權利。
