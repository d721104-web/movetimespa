## 飯店到房按摩預約前，先確認這 5 件事

| 要確認 | 建議做法 |
| --- | --- |
| 飯店是否允許外部服務人員 | 先打電話或問櫃台 |
| 如何進入 | 是否要登記、換證、住客下樓接人 |
| 房間是否適合服務 | 有穩定平躺位置與基本移動空間 |
| 預約時間 | 留意 Move Time 10:00–23:00；21:00–23:00 為加價時段 |
| 地址與房號 | 地址先提供客服，房號可依住宿安全規則適時提供 |

## 1. 先問飯店，不要讓按摩師到門口才被擋

不同飯店、旅館與民宿對外部訪客的規則不同。有些可以登記後上樓，有些要求房客親自接待，也有些基於安全或管理政策不允許外部服務人員進客房。

因此最有效率的方法不是先把按摩訂好，而是先問櫃台：

> 「住宿期間可以讓外部預約的按摩服務人員進房嗎？需要怎麼登記？」

得到明確答案後，再和 Move Time 客服確認時段。

## 2. 飯店房間不一定有按摩床，空間要先看

Move Time 目前到府服務不攜帶按摩床，所以飯店房間同樣需要有適合服務的位置。一般可以先評估床鋪、足夠穩定的平躺位置，以及按摩師是否有基本移動空間。

如果房型非常小、床邊幾乎沒有空間，建議預約前先說明，避免服務人員到場後才發現無法安全操作。

## 3. 旅客最常見的需求：走很多路、肩頸累、想直接休息

台南旅遊常見行程會在景點、商圈與餐廳之間走動。到晚上不想再搭車出門，是飯店到房服務最直接的價值。

如果主要是雙腳疲累，可以看腳底 60 分鐘；如果肩頸與上背比較明顯，可以看肩頸 60 分鐘；如果多部位都想安排，就可以比較 90 分鐘全身服務。選擇方式可看 <a href="/guide/massage-duration/">按摩 60／90 分鐘怎麼選？</a>。

## 4. 晚上預約，要留意 21:00–23:00 加價時段

Move Time 每日服務時間為 10:00–23:00，21:00–23:00 為加價時段。旅客常在晚餐後才回飯店，所以如果預計 9 點後安排，建議在詢問時就一起確認當次費用。

熱門週末、連假或大型活動期間，可接單人力可能比較緊，越早詢問越容易確認。

## 5. 房號與個資不用過度公開

預約需要正確地址與聯絡方式，但沒有必要把房號公開張貼在社群或提供給不相關的人。可以透過正式客服在合理必要範圍內完成聯絡；按摩師抵達前，再依飯店規則確認如何會合。

這同時也是為什麼建議避免透過不明私人帳號「臨時約」——正式管道比較容易保留預約紀錄與聯絡窗口。

## 6. 飯店業者想把到房服務變成固定合作，也有另一條路

如果你是飯店、民宿、旅館或企業窗口，不是單一旅客預約，而是希望建立固定合作、住客轉介或服務流程，可以直接查看 <a href="/partner/">Move Time 飯店／企業合作專區</a>。

合作需求和一般客人單次預約不同，適合另外確認預約方式、接待流程與合作條件。
