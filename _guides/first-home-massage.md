## 先用 5 分鐘完成這張準備清單

第一次安排到府按摩，可以在服務前照這張表快速確認：

| 要確認的事 | 建議怎麼做 | 為什麼重要 |
| --- | --- | --- |
| 日期與時間 | 提供希望日期與大約時段 | 客服才能確認合作按摩師是否可安排 |
| 服務區域 | 告知台南行政區與大致位置 | 到府服務需要一起考量交通與派單 |
| 服務需求 | 說明全身、肩頸、腳底、精油香氛放鬆等需求 | 方便安排適合的服務項目與時間 |
| 服務空間 | 準備可平躺、穩定且不擁擠的位置 | Move Time 目前不攜帶按摩床 |
| 重點與避開部位 | 先說最想加強、完全不希望碰觸的部位 | 讓現場溝通更清楚，也尊重個人界線 |
| 特殊狀況 | 懷孕、近期手術、明顯不適、過敏等先說明 | 便於判斷是否適合照原計畫安排；有醫療疑慮應先詢問合格醫療專業人員 |

如果你還沒決定要選哪個服務，可以先看 <a href="/services/">Move Time 服務與價格</a>；若最在意費用，也可以先看 <a href="/guide/home-massage-price/">台南到府按摩價格怎麼算？</a>。

## 1. 預約時，不用講得很專業，只要提供 4 個資訊

很多第一次預約的人會卡在「我不知道自己要選哪一種按摩」。其實不用先研究所有手法，只要先告訴客服：

1. **日期與時間**：例如「星期六晚上 7 點左右」。
2. **服務地區**：例如台南安平區、東區或中西區。
3. **大致需求**：例如久坐後想集中肩頸、走很多路想放鬆雙腳，或希望安排較完整的全身服務。
4. **其他偏好**：例如希望指定男／女按摩師、希望避開某個部位，或有其他需要事先確認的情況。

目前 Move Time 主要服務台南市<strong>東區、北區、中西區、南區、安平區與安南區</strong>；其他區域可以先詢問，再依當日合作按摩師與交通狀況確認。完整服務方式可參考 <a href="/tainan-home-massage/">台南到府按摩完整指南</a>。

<p class="note">指定男／女按摩師屬於預約偏好，是否能安排仍以當日可接單人員為準。越早提出，通常越容易確認。</p>

## 2. 家裡最重要的是「能舒服躺下」，不是要有專業按摩房

Move Time 到府服務目前<strong>不攜帶按摩床</strong>。因此第一次預約前，最需要確認的是服務位置。

適合的空間可以是：

- 床墊或床鋪
- 穩定的沙發床
- 瑜珈墊搭配適合的軟墊
- 其他能讓人穩定平躺、按摩師也能安全移動的位置

不需要特別把客廳重新裝潢，也不需要準備香氛燈、專業器材或購買按摩床。比起「看起來像不像 SPA」，更重要的是：<strong>穩定、乾淨、隱私足夠，而且按摩師周圍有基本活動空間。</strong>

### 空間不大怎麼辦？

一般住宅不需要很大。建議先把地上的雜物、電線、容易絆倒的物品移開；若家中有幼童或寵物，也可以先安排在不會突然進出服務區的位置。這不只是舒適度問題，也能減少服務途中被打斷或絆倒的風險。

## 3. 穿什麼比較好？以「舒服、方便溝通」為原則

如果是一般指壓、肩頸或全身放鬆，通常以<strong>乾淨、寬鬆、不妨礙活動的衣物</strong>最方便。不要為了按摩刻意穿很正式或很緊身的衣服。

若預約的服務需要使用精油或涉及衣物調整，現場應先把流程、服務範圍與個人界線說清楚。你可以隨時表示哪些部位不希望服務、希望保留哪些衣物，或要求調整方式。<strong>任何服務都應以本人同意與舒適度為前提。</strong>

是否要先洗澡沒有硬性規定。若剛從戶外回家、自己洗澡後會比較放鬆，可以先洗；如果時間來不及，也不用因為這件事取消預約。

## 4. 服務前不用空腹，但不要在明顯不適時勉強安排

到府按摩不是需要空腹的檢查。一般情況下照平常作息即可，但如果剛吃完非常大量的餐食、飲酒過量，或當天有發燒、明顯身體不適等情況，與其硬做，通常更適合先告知客服並評估是否改期。

如果有以下情況，預約前建議主動說明：

- 懷孕或孕期有特殊狀況
- 近期手術、外傷或仍在恢復
- 已知對特定精油、乳液或成分過敏
- 某些部位不希望碰觸
- 有醫師交代需要避免的動作或部位
- 目前身體狀況讓自己不確定是否適合一般按摩

Move Time 提供的是一般按摩與放鬆舒緩服務，<strong>不涉及醫療診斷、治療、復健或療效保證</strong>。如果問題本身屬於疾病、受傷或醫療判斷，應優先詢問合格醫療專業人員，而不是請按摩師代替診斷。

## 5. 力道、重點部位與「不要碰哪裡」，最好一開始就說

第一次見到按摩師，很多人會不好意思說：「這裡不要按」、「太大力了」、「我比較想做肩頸」。其實這些資訊越早說越好。

服務前可以直接講：

> 「今天最想放鬆肩頸跟上背。」
>
> 「右膝附近先不要碰。」
>
> 「我比較怕痛，力道先輕一點。」

服務開始後也可以隨時調整。力道不是越大越專業；到府服務的重點，是在雙方清楚溝通的情況下完成適合當下需求的放鬆安排。

## 6. 按摩師到達之後，大致會怎麼進行？

第一次預約可以先知道流程，就比較不會緊張：

1. **到達與基本確認**：確認預約人、服務項目與服務位置。
2. **服務前溝通**：說明今天最想加強的部位、偏好力道、需要避開的位置。
3. **開始服務**：依實際項目與當下狀況進行，過程中可隨時反映舒適度。
4. **服務結束**：確認服務完成、整理個人物品與現場。
5. **在家直接休息**：不用再開車或移動回家，這也是到府服務最大的便利之一。

Move Time 每日服務時間目前為<strong>10:00–23:00</strong>，其中 21:00–23:00 為加價時段。實際可預約時間與費用，以客服確認為準。

## 7. 有家人、小孩或寵物在家，可以預約嗎？

可以，但最好事先想一下服務期間會不會一直被打斷。

如果有家人同住，可以先告知服務期間需要一段相對安靜的時間；有幼童或寵物時，則建議有人協助照顧，或讓寵物待在另一個安全空間。這樣不只是讓自己比較放鬆，也能避免按摩師移動時突然被碰撞。

如果是在飯店、民宿或其他住宿場所預約，還要先確認住宿業者對外部服務人員進入客房的規定。不同場所規則可能不同，不要等按摩師抵達後才發現無法進入。

## 一張圖概念：第一次預約其實只要做到「4＋1」

可以把整篇濃縮成：

**4 個預約資訊**

> 日期時間 ＋ 台南區域 ＋ 想做的服務／部位 ＋ 特殊偏好

再加上：

**1 個適合服務的空間**

> 穩定、舒服、乾淨、能平躺，而且周圍有基本活動空間。

做到這些，就已經足夠完成大多數第一次預約前的準備。

## 第一次預約前，最後再確認一次

如果你已經準備好預約，傳給客服的訊息其實可以很簡單：

> 「想預約星期六晚上 7 點，地點在台南東區，主要想放鬆肩頸，希望女按摩師；家裡有床可以服務。」

有了日期、區域、需求與現場條件，客服就能開始幫你確認。若還不知道要選 60 分鐘還是 90 分鐘，可以直接看 <a href="/guide/massage-duration/">按摩 60 分鐘、90 分鐘怎麼選？</a>；如果還想比較不同服務，也可以先從服務頁與價格文章開始看。
